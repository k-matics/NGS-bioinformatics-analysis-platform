Parameter presets

A preset is a saved set of workflow parameters. Choose one on a sample's Start a workflow form: it fills in the fields, you can still change any of them, and the run records which preset it started from and which values you changed.

Grab the filtering profile of a VCF

Reads the VCF's header (caller, command line, every ##FILTER rule) and its records (which filters were really applied, and the lowest QUAL/DP/GQ/VAF among PASS calls), then proposes matching values for our per-caller filters. Each value is labelled mapped, approximate or not mappable on the preset's page. The VCF is only read.
